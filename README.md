# Day 2 - Functions and Arrays in JavaScript

This repository contains JavaScript exercises on functions and arrays.

## Exercises

### 1. Calculate Average
- Create a function to calculate the average of an array of numbers.

### 2. Celsius to Fahrenheit Conversion
- Use `map()` to convert an array of Celsius temperatures to Fahrenheit.

### 3. Filter Students
- Use `filter()` to extract students who scored above 60.

### 4. Student Grade Calculator
- Use `forEach()` to calculate and display grades (A, B, C, F) based on student scores.

## Technologies Used
- JavaScript
- Node.js (optional)
- VS Code
